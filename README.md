# 🚀 NASA Space Apps Challenge – UI/UX Project

This project is a responsive web UI created for the **NASA Space Apps Challenge**, designed to provide participants with an intuitive, engaging platform to explore event information, register, and interact with content.

---

## 🔍 Overview

- **Purpose**: Design a clean and user-friendly interface for a space/hackathon event.
- **Tech Stack**: HTML, CSS, JavaScript
- **Focus**: UI/UX design principles, responsiveness, and visual storytelling.

---

## 🎯 Features

- 🎨 NASA-themed modern visual design
- 🧭 Easy navigation with clear CTAs
- 🗓️ Schedule and registration sections
- 🌐 Compatible across major browsers

---

## 🛠️ Tools Used

- **Design**: Figma (for wireframes and mockups)
- **Development**: HTML5, CSS3, JavaScript
- **Version Control**: Git & GitHub
